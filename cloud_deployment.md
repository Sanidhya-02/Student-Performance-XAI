This document records the cloud deployment work completed for the
Student Performance Prediction System. The application was developed
using Python, Streamlit, scikit-learn and SHAP, and deployed as a
publicly accessible web application using Streamlit Community Cloud.

## 2. Cloud Platform Used

**Streamlit Community Cloud** is a managed application-hosting platform
for Streamlit applications. It connects to a GitHub repository, installs
the Python dependencies, and runs the configured Streamlit entry-point
file.

For this project, Streamlit Community Cloud provides the hosting
environment. Users can access the application through its public URL
without installing Python or running the application on their own
computers.

## 3. Deployment Architecture

The deployed application follows this basic architecture:

``` text
User's web browser
        |
        | HTTPS request
        v
Streamlit Community Cloud
        |
        | Runs app.py
        v
Student Performance Dashboard
        |
        +---- Student input and prediction interface
        |
        +---- Trained Random Forest model
        |
        +---- SHAP explainer for feature contributions
        |
        +---- What-if analysis and batch CSV prediction
```

The application loads the trained model and SHAP explainer from the
repository's `models/` directory. Predictions and explanations are
generated by the application when a user interacts with the dashboard.

## 5. Deployment Procedure

The following steps were performed to deploy the application:

1.  Created a GitHub repository for the project and pushed the project
    files to the `main` branch.
2.  Checked that the trained model and SHAP explainer files were
    included in the repository.
3.  Opened Streamlit Community Cloud and signed in using GitHub.
4.  Selected the **Create app** option.
5.  Selected the GitHub repository
    `Sanidhya-02/Student-Performance-XAI`.
6.  Selected the `main` branch.
7.  Set the main file path to `app.py`.
8.  Chose an available Streamlit application URL.
9.  Started the deployment.
10. Waited for Streamlit Community Cloud to install the dependencies and
    start the application.
11. Opened the generated public URL and verified that the dashboard
    loaded.

## 7. Cloud Computing Concepts Demonstrated

This deployment demonstrates the following cloud-computing concepts:

-   **Cloud hosting:** The application is hosted on an
    internet-accessible cloud platform rather than being restricted to
    the developer's local machine.
-   **Platform as a Service (PaaS)-style deployment:** The hosting
    platform manages much of the application runtime and deployment
    environment. The developer supplies the application code and
    dependencies.
-   **Managed application deployment:** The application is connected to
    a GitHub repository and deployed through the platform's deployment
    workflow.
-   **Remote accessibility:** Users can access the application through a
    public URL using a web browser.
-   **Dependency management:** The platform uses the project's
    `requirements.txt` file to install the Python packages required by
    the application.
-   **Version-controlled deployment source:** The deployed application
    is associated with a repository and branch in GitHub.

## 8. Limitations and Scope

-   The application is hosted using Streamlit Community Cloud; it is not
    a self-managed virtual machine or a custom cloud infrastructure
    deployment.
-   No separate cloud database or cloud storage service was configured
    as part of this deployment.
-   The model and SHAP explainer are stored as files in the GitHub
    repository and loaded by the application.
-   Application availability, resource limits and hosting behaviour are
    subject to the platform's current service terms and limits.
-   The project uses a synthetic dataset for demonstration. Its
    predictions should not be treated as validated assessments of real
    students.
